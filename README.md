# 포켓몬 GO 도감

도감번호(또는 한글/영문 이름)를 입력하면 포켓몬 GO 기준 정보를 보여주는 웹 프로그램입니다.

## 실행 방법
`index.html` 파일을 브라우저로 열면 됩니다. 서버나 설치가 필요 없습니다.
주소 뒤에 `#번호`를 붙이면 해당 포켓몬이 바로 열립니다 (예: `index.html#150`).

## 기능
- **기본 정보**: 타입(속성), 폼(알로라·가라르·히스이·메가 등), GO 출시 여부
- **기본 능력치**: GO 공격 / 방어 / 체력
- **최대 CP**: 개체값 15/15/15 기준 레벨 40 / 50 / 51
- **약점 속성**: 받는 피해 배율 (×2.56, ×1.6, ×0.625, ×0.391 …)
- **강점 속성**: 자기 타입 기술이 효과 굉장(×1.6)인 상대 타입
- **상황별 CP 범위**: 필드 리서치(Lv15), 레이드·알(Lv20), 날씨 부스트(Lv25), 야생 최대
- **개체값 계산기**: 공/방/체 개체값 + 레벨 → CP, HP, 슈퍼·하이퍼리그 최적 레벨, 레벨별 CP 표
- **CP로 개체값 추정**: 게임의 CP(+HP)로 가능한 레벨·개체값 조합 찾기

## 디스코드 웹훅 연동
화면의 **📤 디스코드로 보내기** 버튼을 누르면 현재 결과(도감 정보 / 개체값 계산 / CP 개체 추정)가 디스코드 채널에 전송됩니다.

- 상단 **디스코드 웹훅 설정**에 웹훅 주소를 넣고 저장 (브라우저에 저장됨), 또는
- `config.example.js` 를 `config.js` 로 복사해 `WEBHOOK_URL` 입력 (git 에 올라가지 않음)

웹훅 주소는 채널 설정 → 연동 → 웹후크에서 만들 수 있습니다. 비밀번호처럼 다뤄 주세요.

## 데이터 갱신
```
python3 scripts/build_data.py <JSON 다운로드 폴더>
```
데이터 출처: [pogoapi.net](https://pogoapi.net) (GO 능력치·타입·CP 배율), [PokeAPI](https://pokeapi.co) (한국어 이름).
