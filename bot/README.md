# 포켓몬 GO 도감 디스코드 봇

## 명령어
| 명령어 | 예시 | 설명 |
|---|---|---|
| `/도감 포켓몬 [폼]` | `/도감 포켓몬:6` | 타입, 능력치, 최대 CP(Lv40/50/51), 상황별 CP, 약점·저항·강점 속성 |
| `/cp 포켓몬 공격 방어 체력 [레벨] [폼]` | `/cp 포켓몬:뮤츠 공격:15 방어:14 체력:15 레벨:40` | CP, HP, 슈퍼·하이퍼리그 최적 레벨, 레벨별 CP |
| `/개체 포켓몬 cp [hp] [최소개체] [폼]` | `/개체 포켓몬:리자몽 cp:2889 hp:158` | 게임 CP(·HP)로 가능한 레벨·개체값 조합 |
| `/일정 [종류]` | `/일정 종류:다가오는 일정` | 포켓몬 GO 현재/다음 일정 |
| `/획득 포켓몬` | `/획득 포켓몬:피츄` | 포켓몬 GO 획득 경로 |
| `/배틀 포켓몬 [폼]` | `/배틀 포켓몬:마릴리` | 슈퍼·하이퍼·마스터·메가마스터 리그별 배틀 개체 1~10위 |

포켓몬 이름과 폼은 입력하는 동안 자동완성됩니다. (슬래시 명령어는 모든 채널에서 동작)

### 채널별 기능
| 채널 (이름에 포함되면 감지) | 반응하는 입력 | 바꾸는 변수 |
|---|---|---|
| `포켓몬개체정보방` | `111`, `888-2`, `리자몽`, `자시안-2` (도감 정보) | `DEX_CHANNELS` |
| `배틀개체정보방` | `배틀111`, `배틀888-2` (배틀 개체 순위) | `PVP_CHANNELS` |
| `배틀신청` (예: `#배틀신청방`) | `배틀신청 닉네임`, `배틀신청 확인`, `배틀신청 수락`, `배틀 종료` | `BATTLE_CHANNELS` |
| `포켓몬획득정보` (예: `#포켓몬획득정보방`) | `111`, `리자몽` (획득 경로) | `ACQ_CHANNELS` |
| `포켓몬고일정` | `현재일정`, `다음일정` | `SCHEDULE_CHANNELS` |
| `친코등록` | `친코등록 1234 5678 9012`, `친코확인 닉네임` | `FRIEND_CHANNELS` |
| `내위치` | `내위치` (내 10진법 좌표), `뉴욕` 등 도시 이름 (핵심 장소 좌표), `도시목록` | `LOCATION_CHANNELS` |

다른 채널에서는 위 입력에 반응하지 않습니다. 봇이 켜질 때 서버별로 어느 채널이 연결됐는지 로그에 나옵니다.

### 배틀신청
이름에 `배틀신청` 이 들어간 채널에 `배틀신청 닉네임` 을 적으면, 봇이 그 사람을 멘션하며
"**닉네임** 님과 배틀신청이 완료되었습니다." 라고 답합니다.
- 서버 닉네임 또는 디스코드 아이디로 찾습니다 (정확히 일치 우선). 비슷한 사람이 여럿이면 후보를 보여 줍니다.
- `배틀신청 @닉네임` 처럼 멘션으로 적으면 가장 정확합니다.
- 알림(멘션)은 배틀신청 받은 사람에게만 갑니다. 자기 자신·봇에게는 신청할 수 없습니다.
- `배틀신청 확인` → 내가 **받은 신청 / 보낸 신청** 목록 (대기 중 / 수락됨, 언제). 아무에게도 알림이 가지 않습니다.
- `배틀신청 수락 닉네임` → 그 사람의 신청을 수락하고 신청자를 멘션해 알려 줍니다. `배틀신청 수락` 만 쓰면 가장 최근 신청을 수락합니다.
- `배틀 종료` (또는 `배틀종료`) → 내가 받은·보낸 배틀신청을 모두 `배틀신청 확인` 목록에서 지웁니다. `배틀 종료 닉네임` 은 그 상대와의 신청만 지우고 상대에게 알립니다.
- 기록은 따로 저장하지 않고 채널의 최근 봇 메시지(최대 500개)를 읽어 계산하므로 봇이 재시작돼도 유지됩니다.
- 채널은 `BATTLE_CHANNELS` 로 바꿀 수 있습니다 (기본값 `배틀신청`).

### 획득 경로
`#포켓몬획득정보방` 에 도감번호나 이름을 적으면(또는 `/획득`) 포켓몬 GO 획득 경로를 보여 줍니다.
- 야생 출현(+날씨 부스트), 둥지, 알 부화(베이비), 전설·환상·울트라비스트, 레이드/리서치/포토밤/GO 배틀리그 전용, 지역 한정, 변장한 메타몽
- 진화로 얻기 / 다음 진화: 사탕 수, 진화 아이템, 루어, 파트너 거리, 낮·밤, 성별, 교환 시 무료 등 조건
- 이로치 출시 여부
- **현재** 레이드·알·이벤트 출현 목록은 시기마다 바뀌어 포함하지 않습니다. 데이터는 `scripts/build_acquire.py` 로 `acquire.json` 을 다시 만들어 갱신합니다.

### 포켓몬 GO 일정
`#포켓몬고일정` 채널에 `현재일정` 을 적으면 지금 진행 중인 일정(곧 끝나는 순), `다음일정` 을 적으면 다가오는 일정(가까운 순)을 최대 15개 보여 줍니다. `/일정` 으로도 볼 수 있습니다.
- 커뮤니티 데이·레이드·스포트라이트 아워·맥스 먼데이·GO 배틀리그·시즌 등, 한국 시간·남은 시간·포켓몬 한국어 이름·자세히 보기 링크
- 데이터: [LeekDuck](https://leekduck.com/events/) 일정을 JSON 으로 정리한 [ScrapedDuck](https://github.com/bigfoott/ScrapedDuck). 요청할 때 받아오고 15분 캐시 → 일정이 바뀌면 자동 반영
- 일정 이름은 영어 원문입니다 (종류는 한국어로 표시)

### 친구 코드 (친코)
`#친코등록` 채널에서:
1. `친코등록 1234 5678 9012` → "친코등록이 완료되었습니다." (12자리 숫자, 띄어쓰기·`-` 허용)
   - 코드가 보이지 않게 봇이 입력 메시지를 지웁니다 (**봇에 '메시지 관리' 권한 필요**).
   - 코드는 암호화해서 봇 메시지의 버튼 안에 보관 → 수락 전에는 아무도 볼 수 없고, 봇이 재시작돼도 유지됩니다.
   - 다시 등록하면 새 코드가 쓰이고, `등록 삭제` 버튼(본인만)으로 지울 수 있습니다.
2. 다른 멤버가 `친코확인 닉네임` (또는 `@멘션`) → 등록한 사람을 멘션하며 "수락하시겠습니까?" + `수락` / `거절` 버튼
3. **등록한 본인만** 버튼을 누를 수 있고, 수락하면 `친코 : 1234 5678 9012` 가 요청한 사람에게 표시됩니다.

암호화 키는 `FRIEND_CODE_SECRET` (없으면 봇 토큰) — 봇 토큰을 바꾸면 기존 등록은 다시 해야 하므로, 오래 쓸 거면 Railway Variables 에 `FRIEND_CODE_SECRET` 을 아무 긴 문자열로 넣어 두세요.

### 새 멤버 환영 메시지
새 멤버가 서버에 들어오면:
- 이름에 `공지` 가 들어간 채널(예: `#공지방`)에 그 멤버를 멘션하며 서버 규칙과 봇 사용법 안내 (`NOTICE_CHANNELS`)
- 이름에 `메인정보방` 이 들어간 채널에 "어서오세요~ 공지방가서 공지한번만 읽어주세요~ 봇사용법 나와있습니다~" (`GREET_CHANNELS`)
- 문구는 `bot/welcome.js` 에서 바꿀 수 있습니다.
- **필수:** Developer Portal → Bot → Privileged Gateway Intents → **SERVER MEMBERS INTENT** 켜기. 꺼져 있으면 환영 메시지만 빠지고 나머지 기능은 그대로 동작합니다 (로그에 안내).

### 내 위치 (10진법 좌표)
디스코드는 봇에게 사용자 위치를 주지 않으므로, 휴대폰 브라우저의 위치 기능을 씁니다.
1. `#내위치` 에서 `내위치` → **📍 내 위치 링크 받기** 버튼
2. 버튼을 누른 사람에게만 보이는 1회용 링크 (10분)
3. 링크를 열고 위치 권한 허용 → `37.566535, 126.977969` 처럼 표시, 좌표 복사·지도 보기
4. **디스코드에 보내기** 를 누르면 채널에 좌표 게시 (안 누르면 나만 봄)

**설정 필요:** 이 페이지는 봇이 같이 띄우는 작은 웹 서버(`PORT`)에서 나옵니다.
Railway → Hihhi 서비스 → **Settings → Networking → Generate Domain** 을 누르면 주소가 생기고(`RAILWAY_PUBLIC_DOMAIN`), 봇이 자동으로 사용합니다. 다른 주소를 쓰려면 `PUBLIC_URL` 변수를 넣으세요.

### 도시 핵심 장소 좌표
`#내위치` 에 도시 이름(예: `뉴욕`, `서울`, `도쿄`, `London`, `NYC`)을 적으면 그 도시의 핵심 장소 TOP 10 을 `이름 : 위도, 경도` 로 보여 줍니다. `도시목록` 으로 지원 도시(57곳)를 볼 수 있습니다.
- 순위: 위키백과 문서가 있는 언어 수가 많은 순(많이 알려진 곳). 사건·학교·교통망·강·도시 중심에서 50km 넘는 곳은 제외
- 데이터: Wikidata (QLever 로 조회), `scripts/build_cities.py` 로 `cities.json` 재생성. 도시 추가는 스크립트의 `CITIES` 목록에 Wikidata ID 추가

### 속성 아이콘
속성은 색 원 안에 흰 문양이 있는 아이콘으로 표시됩니다. 봇이 켜질 때 `type-icons/` 의 이미지 18개를 **봇 전용 이모지**로 자동 등록하므로
서버마다 이모지를 따로 올릴 필요가 없습니다. 등록에 실패하면 기본 이모지(🔥💧 등)로 표시됩니다.
Developer Portal → 앱 → **Emojis** 에서 등록된 아이콘을 볼 수 있습니다.

### 모습변화 포켓몬 (`번호-모습`)
기본 모습과 능력치·타입이 다른 모습이 있는 포켓몬은 `-1` 이 기본 모습, `-2` 부터 변화 모습입니다 (메가는 맨 뒤).
- `888-1` / `배틀888-1` → 자시안 (역전의 용사), `888-2` / `배틀888-2` → 자시안 (검왕)
- `6-1` 리자몽, `6-2` 메가리자몽 X, `6-3` 메가리자몽 Y
- 번호만 적으면(`888`) 기본 모습. `/도감 888` 결과 아래에 모습별 번호 목록이 나옵니다.
- 슬래시 명령어의 `폼` 옵션도 같은 번호(1 = 기본)를 씁니다.

### 배틀 개체 순위
`#배틀개체정보방` 채널에 `배틀111`, `배틀 6`, `배틀리자몽` 처럼 적으면 리그별 1~10위(총 40개)를 보여줍니다.
- 기준: 최대 레벨 50, CP 상한 이하에서 스탯곱(공격×방어×HP)이 큰 순
- 그림자 표도 함께 나옵니다 (그림자는 공격 ×1.2·방어 ×0.83이라 순위는 일반과 같고, 그림자 기준 실제 공격·방어를 표시. 메가진화 불가라 메가마스터 제외)
- 메가마스터리그는 메가진화 능력치로 계산 (메가가 여러 개면 첫 번째, `/배틀` 의 `폼` 옵션으로 선택 가능)

### 채널에 도감번호만 입력하기
`#포켓몬개체정보방` 채널에 `25`, `#150`, `6번`, `No.6` 처럼 **도감번호만** 적으면 봇이 그 포켓몬 정보를 답장합니다.
(다른 말과 섞인 숫자, 예: `25마리 잡았다` 는 무시합니다)

- 감지할 채널은 `DEX_CHANNELS` 로 바꿀 수 있습니다 (채널 이름 또는 ID, 쉼표로 여러 개, 기본값 `포켓몬개체정보방`, `*` 은 모든 채널).
  채널 이름에 그 글자가 **들어가기만 하면** 됩니다 (`💬｜포켓몬개체정보방` 등도 해당). 여러 서버에서 동작합니다.
- 봇이 켜질 때 서버별 감지 채널이 로그에 나오고, 감지 채널이 없거나 권한이 부족하면 경고가 나옵니다.
- **필수:** Developer Portal → Bot → *Privileged Gateway Intents* 에서 **MESSAGE CONTENT INTENT** 를 켜야 합니다.
- 봇에게 해당 채널의 *메시지 보기 / 메시지 보내기 / 링크 첨부* 권한이 있어야 합니다.

## 설치 및 실행
1. [Discord Developer Portal](https://discord.com/developers/applications) → **New Application**
2. **Bot** 탭 → **Reset Token** 으로 토큰 복사
3. 같은 Bot 탭의 **Privileged Gateway Intents** 에서 **MESSAGE CONTENT INTENT** 켜기
4. **OAuth2 → URL Generator** 에서 `bot`, `applications.commands` 체크, 권한은 `Send Messages`, `Embed Links`, `Read Message History` → 생성된 URL로 서버에 초대
5. 이 폴더에서:
   ```
   cp .env.example .env     # .env 에 DISCORD_TOKEN 입력 (GUILD_ID 는 선택)
   npm install
   npm start
   ```
   `GUILD_ID` 에 서버 ID를 넣으면 명령어가 바로 보이고, 비워두면 전역 등록이라 최대 1시간 걸릴 수 있습니다.

Node.js 20.12 이상이 필요합니다. 봇 실행 중에는 컴퓨터(또는 서버)가 켜져 있어야 합니다.

## 테스트
`npm test` — 토큰 없이 계산값과 Discord 메시지 길이 제한을 검사합니다.

데이터는 상위 폴더의 `data.js` 를 사용합니다 (`scripts/build_data.py` 로 갱신).

## 웹훅으로 보내기 (봇 토큰 없이)
웹훅은 명령어를 받을 수는 없고, 결과 메시지를 채널에 **보내기만** 합니다.
`.env` 에 `WEBHOOK_URL` 을 넣고:
```
node webhook.js 도감 리자몽
node webhook.js cp 뮤츠 15 14 15 40
node webhook.js 개체 리자몽 2889 158
```
웹훅 URL은 비밀번호처럼 다뤄 주세요 (아는 사람은 누구나 채널에 글을 쓸 수 있습니다).

## Railway 로 24시간 실행하기
저장소 루트의 `package.json` / `railway.json` 으로 바로 배포됩니다 (`npm start` → `node bot/index.js`).

1. https://railway.com 에 GitHub 로 가입
2. **New Project → Deploy from GitHub repo → Hihhi** 선택 (Root Directory 는 비워 둠)
3. 서비스의 **Variables** 에 추가
   - `DISCORD_TOKEN` = 봇 토큰 (필수)
   - `WEBHOOK_URL` = 웹훅 주소 (선택)
   - `DEX_CHANNELS` / `PVP_CHANNELS` / `BATTLE_CHANNELS` (선택, 기본값: 포켓몬개체정보방 / 배틀개체정보방 / 배틀신청)
   - `GUILD_ID` = 서버 ID (선택)
4. 배포 로그에 `✅ ... 로그인 완료` 가 보이면 `#포켓몬개체정보방` 에 `111` 입력해서 확인
