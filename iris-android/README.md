# 아이리스 — 화면 꺼져도 대답하는 음성 비서 (안드로이드)

갤럭시 노트20(루팅) 기준으로 만든 앱입니다. "아이리스"라고 부르면 삑 소리가 나고, 이어서 말한 명령을 Claude가 처리해 음성으로 대답합니다.

## 동작 방식
1. **호출어 감지**: Vosk 한국어 모델로 폰 안에서 오프라인으로 계속 듣습니다(처음 켤 때 약 80MB 모델을 내려받습니다).
2. **명령 듣기**: 삑 소리 뒤에 구글 음성인식으로 한 문장을 받아씁니다.
3. **처리**: Claude API가 대답하고, 필요하면 아래 도구를 씁니다.
4. **대답**: 한국어 TTS로 읽어 줍니다. 아이리스가 되묻는 경우에는 호출어 없이 바로 대답하면 됩니다.

## 할 수 있는 일
| 분류 | 예시 |
|---|---|
| 일정 | "내일 오후 3시에 치과 예약 잡아줘", "이번 주 일정 알려줘", "그 일정 지워줘" |
| 알람/타이머 | "내일 아침 7시 알람 맞춰줘", "라면 타이머 3분" |
| 질문 | "오늘 서울 날씨 어때?", "환율 얼마야?" (웹 검색 포함) |
| 앱 설치 | "F-Droid 설치해줘" (공식 APK 주소를 찾아 루트로 바로 설치), 플레이스토어 앱은 페이지를 열어 줌 |
| 앱 실행/삭제 | "카카오톡 열어줘", "○○ 앱 지워줘" |
| 기기 조작 | "와이파이 꺼줘", "밝기 최대로", "블루투스 켜줘" (루트 셸 명령) |

설치, 삭제, 설정 변경 같은 작업은 실행하기 전에 "할까요?" 하고 묻습니다. "응"이나 "네"라고 하면 실행합니다.

## 설치 방법
1. `app-release.apk`를 폰에 받아 설치합니다(출처를 알 수 없는 앱 허용 필요).
2. 아이리스 앱을 열고 마이크, 캘린더, 알림 권한을 허용합니다.
3. **Claude API 키**를 넣고 "설정 저장"을 누릅니다(https://console.anthropic.com 에서 발급, 사용량만큼 과금).
4. **"배터리 최적화에서 제외"**를 누르고 허용합니다.
5. "아이리스 켜기"를 누르면 Magisk가 루트 권한을 물어봅니다. **허용**해 주세요.
6. 처음 켜면 음성 모델(약 80MB)을 내려받습니다. 알림이 "대기 중"으로 바뀌면 준비가 끝난 것입니다.

### 삼성 폰 추가 설정(중요)
- 설정 → 배터리 → 백그라운드 사용 한도 → **"사용하지 않는 앱을 절전 상태로 전환" 끄기**, 아이리스를 **"절전 예외 앱"**에 추가하세요.
- 설정 → 애플리케이션 → 아이리스 → 배터리 → **"제한 없음"**으로 설정하세요.
- 구글 음성인식이 꺼진 화면에서 잘 되지 않으면 설정 → 일반 → 음성 입력에서 "Google 음성 인식"을 선택하세요.

## 직접 빌드
```bash
cd iris-android
./gradlew assembleRelease   # app/build/outputs/apk/release/app-release.apk
```
안드로이드 SDK 경로는 `local.properties`의 `sdk.dir`에 적습니다.

## 알아둘 점
- 상단 알림줄에 "아이리스" 알림이 항상 떠 있습니다. 화면이 꺼진 동안 마이크를 쓰려면 안드로이드가 이 알림을 반드시 요구합니다.
- 계속 듣는 만큼 배터리가 평소보다 더 닳습니다.
- 기본 모델은 `claude-opus-5-5`입니다. 더 빠르고 저렴하게 쓰려면 앱에서 `claude-haiku-5-5`로 바꾸세요.
- API 키는 폰 안의 앱 저장소에만 저장됩니다.
