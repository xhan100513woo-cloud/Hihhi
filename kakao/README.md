# 카카오톡 거래글 쿨타임(거쿨) 경고 봇

같은 사람이 같은 방에 **같은 거래글**을 **1시간 안에** 다시 올리면 봇이
`거쿨경고 1 드립니다.` 라고 답합니다.

- 거래글 판단 키워드: `ㄱㄹ`, `거래`, `구매`, `판매`, `ㄱㅁ`, `ㅍㅁ`, `ㅍㅍ`
- 띄어쓰기·줄바꿈·`!?.~` 같은 문장부호만 다른 글은 같은 글로 봅니다.
- 다시 올린 시점부터 1시간을 새로 계산합니다.

## 설치 (안드로이드)
카카오톡은 공식 단톡 봇 API가 없어서, 안드로이드 폰에서 **메신저봇R** 앱으로 알림을 읽고 답장하는 방식입니다.

1. 봇으로 쓸 카카오톡 계정이 로그인된 안드로이드 폰에 **메신저봇R** 설치
2. 앱 권한: 알림 접근 허용, 배터리 최적화 제외
3. 새 봇 만들기 → **레거시 API** 선택 → `trade-cooldown.js` 내용을 전부 붙여넣기
4. 컴파일 → 봇 켜기. 그 계정이 들어가 있는 단톡방에서 동작합니다.
   (카카오톡 알림이 켜져 있어야 하고, 해당 방 알림도 꺼져 있으면 안 됩니다)

## 설정 (`trade-cooldown.js` 맨 위 `CONFIG`)
| 항목 | 기본값 | 설명 |
|---|---|---|
| `KEYWORDS` | 위 7개 | 거래글로 볼 단어 |
| `COOLDOWN_MS` | 1시간 | 쿨타임 |
| `WARNING` | `거쿨경고 1 드립니다.` | 보낼 문구 |
| `ROOMS` | `[]` (모든 방) | 특정 방만: `["포켓몬고 거래방"]` |
| `PER_SENDER` | `true` | `false` 면 누가 올렸든 같은 글이면 경고 |

기록은 메모리에만 있어서 봇을 다시 컴파일/재시작하면 초기화됩니다.
